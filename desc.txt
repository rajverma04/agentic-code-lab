1. PROJECT OVERVIEW (WHAT IS AGENTIC CODELAB?)
-------------------------------------------------------------------------------
Agentic CodeLab is an AI-powered Intelligent Codebase Analyzer and Developer Assistant. 
It acts like a senior software architect that instantly understands any GitHub 
repository, visualizes its architecture in interactive 2D graphs, answers 
technical questions, scans for security bugs, and even automatically edits code 
and creates GitHub Pull Requests.

The Core Problem It Solves:
Developers and team leaders waste hours reading unfamiliar codebases, finding 
where APIs are defined, checking for security flaws, and worrying about breaking 
other files when refactoring code. Agentic CodeLab solves this by automating codebase 
understanding, risk assessment, and code refactoring in seconds.

2. COMPLETE DATA WORK FLOW (STEP-BY-STEP EXPLANATION FOR PRESENTATION)
===============================================================================

[WORKFLOW 1: CODEBASE INGESTION & PROCESSING PIPELINE]
-------------------------------------------------------------------------------
Step 1: User submits a public or private GitHub repository URL (e.g., https://github.com/user/repo).
Step 2: Backend Express server clones the repository to local disk storage (`./temp_repos/:id`).
Step 3: AST Symbol Extraction Engine (`ts-morph` + Regex) scans all `.ts`, `.js`, `.py`, `.java` files:
        - Extracts function names, class definitions, exported methods, imports (`require` / `import`), and API routes.
Step 4: Dependency Graph Construction:
        - Maps caller-callee links between files to build an interactive React Flow node-and-edge dependency graph.
Step 5: Vector Chunking & Embedding:
        - Splits code files into function-level semantic chunks.
        - Generates 768-dimensional vector embeddings and indexes them in Qdrant Vector Store.
Step 6: Database Storage:
        - Saves structured metadata, file inventories, AST symbols, and dependency edges to Supabase PostgreSQL DB via Prisma ORM.
Step 7: Ingestion Progress Auto-Updates:
        - Frontend workspace automatically polls progress (`0% -> 25% -> 50% -> 75% -> 100%`) and displays an animated progress banner until status reaches READY.


[WORKFLOW 2: RUNTIME RAG QUERY & AI CHAT PIPELINE]
-------------------------------------------------------------------------------
Step 1: User types a technical question in AI Code Chat (e.g., "Give me all APIs implemented and their file paths").
Step 2: Intelligent RAG Engine detects query intent:
        - If user asks a global question (e.g., "all APIs", "architecture", "routing"), RAG automatically queries the entire repository file tree + API routes across all files.
        - If user targets a specific file, RAG combines that file's chunks with global vector search.
Step 3: Qdrant Vector Database performs hybrid vector similarity + keyword search to retrieve the top 10 most relevant code snippets.
Step 4: Groq Cloud AI Engine (`qwen/qwen3.6-27b`) processes prompt context:
        - Sanitizes output by stripping internal `<think>` reasoning tags.
        - Synthesizes a clean, professional Markdown response with exact file paths, line numbers, and code blocks.


[WORKFLOW 3: AUTOMATED REFACTORING & GITHUB PULL REQUEST PIPELINE]
-------------------------------------------------------------------------------
Step 1: User enters a refactoring goal in Change Planner (or clicks an AI Suggested Refactoring Proposal card).
Step 2: Change Planner Agent inspects source files and generates modified code proposals.
Step 3: Direct-to-Disk Modification:
        - Agent overwrites files directly on disk and returns a 2-bullet executive summary.
Step 4: 1-Click GitHub Pull Request:
        - Octokit REST API creates a new Git branch (`ai/change-timestamp`), commits edits, and submits a live Pull Request directly to GitHub!


[WORKFLOW 4: REPOSITORY CLEANUP & DELETION PIPELINE]
-------------------------------------------------------------------------------
Step 1: User clicks the red "Delete Cloned Project 🗑️" button on the Landing Page or Workspace header.
Step 2: Backend purges the cloned source directory from disk (`./temp_repos/:id`).
Step 3: Prisma ORM issues a cascading DELETE in Supabase PostgreSQL, clearing all associated files, symbols, chunks, chats, and audit reports.

3. TECH STACK USED & WHY CHOSEN
===============================================================================
A. FRONTEND:
   - Next.js 14 (App Router) + React 18:
     * Why: Fast page loads, clean component architecture, and serverless deployment on Vercel.
   - Tailwind CSS (Dark Glassmorphism UI):
     * Why: Gives a modern, premium, dark-themed visual experience for developer dashboards.
   - React Flow:
     * Why: Renders interactive, draggable 2D Architecture Graphs with color-coded nodes (Controllers, Services, Routes, Models) and glowing dependency lines.
   - Monaco Code Editor (VS Code in Browser):
     * Why: Enables users to inspect and view modified source code files with full syntax highlighting right in the web browser.

B. BACKEND & PARSING:
   - Node.js + Express.js + TypeScript:
     * Why: Handles heavy async I/O operations (cloning repos, scanning files, running AI agents) with strict type safety.
   - ts-morph & RegEx AST Scanners:
     * Why: Parses TypeScript and JavaScript source code to extract exact function definitions, class structures, ES6 imports, and CommonJS require(...) calls accurately.

C. DATABASE & VECTOR SEARCH:
   - Supabase PostgreSQL + Prisma ORM:
     * Why: Enterprise-grade cloud database with connection pooling (Port 5432/6543) that stores repository metadata, AST symbols, and analysis history cleanly.
   - Qdrant Vector Database:
     * Why: Stores high-dimensional vector embeddings of code blocks, allowing the AI to search code semantically (by meaning) rather than simple text search.

D. AI REASONING ENGINE:
   - Groq Cloud API (Qwen 3.6 27B Model):
     * Why: Delivers sub-second, ultra-fast AI responses with zero local disk space usage and zero cost.

4. AI AGENTS BUILT, THEIR ROLES & WHY THEY WERE CREATED
===============================================================================

🤖 AGENT 1: RAG Code Architecture Chat Assistant
   - Role: Answers developer questions about codebase logic, routing, entry points, and data models using exact code context.
   - Why Created: Helps new team members onboard instantly into a new codebase without having to disturb senior developers.

🤖 AGENT 2: Automatic Code Refactoring & Change Planner Agent
   - Role: Takes natural language editing requests, rewrites source code files, saves changes directly to disk, and gives a concise 2-bullet summary.
   - Why Created: Saves developers hours of manual coding and eliminates copy-pasting code diffs back and forth.

🤖 AGENT 3: Automated GitHub Pull Request Agent
   - Role: Automatically creates an isolated Git branch and submits a live Pull Request directly to the user's GitHub repository.
   - Why Created: Automates the entire workflow from AI code generation all the way to version control submission.

🤖 AGENT 4: AI Security & Vulnerability Auditor Agent
   - Role: Audits code for hardcoded API keys/secrets, SQL injection risks, CORS gaps, and unhandled promise rejections, assigning an overall Security Grade (A+ to F).
   - Why Created: Prevents security vulnerabilities and leaked credentials from ever reaching production servers.

🤖 AGENT 5: Code Impact & Blast Radius Assessment Agent
   - Role: Calculates which files, API endpoints, and UI components will be affected if a specific function or module is changed, assigning a Refactoring Risk Rating (LOW, MEDIUM, HIGH, CRITICAL).
   - Why Created: Prevents developers from accidentally breaking downstream components or API routes when changing core code.

🤖 AGENT 6: OpenAPI 3.0 & Markdown Documentation Generator Agent
   - Role: Scans route handlers, request parameters, and database schemas to auto-generate valid OpenAPI 3.0 specs (with 1-click JSON download) and Markdown documentation.
   - Why Created: Keeps API documentation 100% up-to-date automatically without manual documentation writing.

🤖 AGENT 7: Branch-vs-Branch Architecture Comparison Agent
   - Role: Compares base vs feature branches (e.g., main vs feature/proposed) to highlight newly added or deleted AST symbols and architectural drift.
   - Why Created: Gives code reviewers full visibility into structural changes before merging code into production.
